- 连环领奖返回FinishResult.nextTask，含新阶段、进度和状态；已全部领取后Stage钳制最后一段、FinishTimes保留真实已领段数、状态4。重传回执不重复发奖。
- 任务进度、阶段、领取、周刷新进入同步签名。推送15类TaskUpdate；任务ID集合变化时使用完整GameTask替换客户端旧列表，防止旧任务和红点残留。保留正常每日签到和真实可领取任务提示。

- 指定怪、怪物类型采用真实战斗每单位峰值的增量；支持普通关卡和赛季，过滤训练，成功结算或已保存成功回执才计。结算与晚到KillInfo不重复计算。
