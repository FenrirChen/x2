## HTTP补修与边界

保持原容器、Content-Length和完整内容，64KiB分块写入，每块空闲超时30秒，整个发送最多900秒；单重任务入场槽仍保留到传输结束。上传30秒空闲保护、文件大小上限、鉴权、在线禁止导入与备份规则均不改变。

增加save response sent及HTTP response interrupted日志，记录状态、完成分块字节数、总字节数、耗时及异常类型；不记录载荷、token或查询串。completed_bytes是完整分块的下限，不推测失败分块中已传字节。预期断连关闭连接，不反复尝试向已断开的socket发送错误。

没有删除必要战斗原包，也没有扩大导入文件上限或修改APK。生成阶段仍可能接近客户端120秒等待响应头限制；本轮主要修复已观察到的生成成功后整包传输超时。远程需要部署补丁后由原玩家重新下载验收。
