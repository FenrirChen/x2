# 活动协议全量审查（2026-10-12）

## 检查范围与防回归

覆盖七个仍开放的主题活动，以及特别课程、积分活动、星相屋、降临纪念等
既有活动中心回归。已下线的秘宝之海保持关闭，不重新开放未实现业务。

新增 `player/activity_protocol.py`：41 个注册接口必须显式声明归属，分为
共享查询、具体 ActivityType、需核对 activityId 的操作以及未实现接口。
同一映射用于业务入口和缓存入口，缓存不能绕过当前活动的检查。
新增接口但未声明契约会被拒绝，测试还会检查契约集合与注册集合完全相等。

- 日月盈仄记录查询/推送仅适用于 group=99。
- 冬至万物剧情/进度、咖啡经营、问答、奖池、积分、商店按对应 ActivityType 检查。
- 带 activityId 的操作核对当前活动、所属玩法，不能把商店 ID 用作关卡查询。
- 缓存只可在相同状态周期回放；换活动或进入下一轮时不会返回旧模块的数据。
- 主动推送只允许声明过的消息，检查活动归属并严格编码。
- 跨周期完成旧活动战斗时不推送下一活动的进度。
- 可选进度生成或校验失败时记录明确错误，不能中断已经保存的主结算应答。
- 不合法操作按既有协议返回 code=13；编码仍在事务内，失败回滚并给出应答。
