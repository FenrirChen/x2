# 樱花信笺每日掉落限额（2026-10-19）

## 原因与依据

伪生樱之岛的同名信笺有两个道具ID：1104008（开出注连绳）、1104027（开出泷樱花）。已恢复APK的Item表及仓库activity_rotation_catalog.json均保留DropLimit=[7]、DropLimitParam=[{Items:[10]}]；dump.cs中EItemDropLimit.E_Daily=7。原服务端校验了战斗掉落来源，但没有执行这两个道具的跨战斗每日累计限制。

## 实现

在EconomyService._grant的重复来源收据检查之后，统一限制battle与sweep来源的信笺实际发放；每种道具各每日最多10个，以北京时间00:00日切。达到上限只截断该道具，其他战斗奖励照常结算。打开、消耗信笺不恢复当天掉落额度，重放旧结算仍返回原收据而不再次发货。

计数复用activity_state的一条账号行（period=0、daily-pickups/sakura-letters），每日覆盖，不新增每日历史大表或启动扫描。当天首次遇到信笺时，从economy_grants当日成功战斗/扫荡记录恢复数量，因此补丁上线前已领取且已打开的信笺也计入当天额度；已有超过10个的玩家当天停止继续获得，不追扣历史库存。管理员邮件等非掉落来源不占用掉落额度。限额状态、背包及发放收据共享原事务，发放失败全部回滚。

## 验证

专项6项：两种信笺累计截断、重放幂等、消耗不恢复、午夜刷新、旧记录8/40个回填、失败回滚、重建服务保留计数，以及2161021真实进入/连续结算/结算重放（到账7、3、0且均正常结算）。活动、扫荡、礼包、月之荒庭和货币等相关回归154项通过，新增真实关卡专项在6项专项测试中再次通过。
