# 角色战斗及训练经验修复（2026-10-16）

## 行为

战斗旧实现仅增加共享神格经验，没有增加角色经验。现成功结算给battle_entries绑定的自有入场角色加经验，忽略客户端回传经验、队伍造假；失败、Type5训练关、官方试用编队不发自有角色经验。

兼容数值（不宣称为官方独立参战经验公式）：优先用SectionTable.VReward中固定1237907奖励数额，每个入场角色获得同额经验；无固定经验时用battle_costs记载的未退款实际消耗体力×20。排除首通、随机掉落、额外倍率和客户端提交数据。原共享经验奖励保留。

PlayerLevelBonus推进角色等级与剩余经验，最高为账号等级和曲线终点的较小值；不新增封顶溢出经验，原有经验保留。手动升级只收取当前等级缺少的经验，旧超额经验结转。

经验写入处于原结算事务及UUID回执保护内；失败回滚，重发只重放响应。结算等级、经验、升级次数、满级状态均为最新快照；HeroUpdate在结算响应前下发。好感原奖励保留。

## 训练证据

CollegeModule.GetHeroTrainExp RVA0x1AFC734：建筑行+0x50检查EffectType2=8，+0x58读取EffectValue2，第一个值为经验。光之密室1/2/10/30级分别500/800/4000/12000。旧25%规则导致初级角色两小时仅30经验，且建筑升级不提高收益。

开始任务记录buildID和gain_exp；领取时用开始行修正旧错误gain_exp，不取当前建筑等级，重复领取不加经验。取消无经验。已领取历史训练无法可靠重建当时角色及建筑状态，本轮不追溯发奖。
